# ClaudeGPT desktop session manager

The desktop component is the history-preserving [Darkaxt/reframe](https://github.com/Darkaxt/reframe) fork, branch `codex/claudegpt`, based on Reframe 0.10.0. Its pinned source is the `apps/reframe` submodule (`git submodule update --init apps/reframe`). It uses this project's managed patched Claude CLI and existing proxy. Electron source/build/release stays independently versioned; Rust source does not embed or build the GUI. `component.json` distinguishes the source pin from final release/activation status. See the fork's `docs/claudegpt-spec.md` for authoritative requirements and `docs/CLAUDEGPT.md` for configuration, build, archive/recovery and release procedures.

ChatGPT uses the original managed CLI with the existing proxy/auth/model/effort. Anthropic uses a separate hash-pinned copy of the reviewed patched native CLI with Claude subscription authentication and session-only routing overrides. The controlled launcher supplies the Anthropic executable binding and removes an absent `CLAUDE_CONFIG_DIR` rather than passing an empty value. Both roles retain the original native history, project instructions and permission controls. Provider changes preserve the conversation without forcing compaction. No automatic provider switching on failures or refusals. The GUI provider selection is an explicit owner action, independent of proxy maintenance. WSL sessions continue to use their distribution's executable and authentication.

Archive/delete uses a versioned managed thread-cleanup helper (published with the release) and verified transactional-cleanup exact-file runtime through the packaged Python adapter. Its pinned psutil dependency supplies one fresh native process census immediately before mutation, avoiding repeated PowerShell startup while protecting active chats. Machine paths/hashes and private activation receipts belong outside Git. No archive, transcript, credential, user profile or private verification packet belongs in this repository.

Keep the prior installed manager and launcher/state recovery at activation. Do not restart/rebuild the unchanged proxy or repatch the unchanged CLI for GUI-only changes. Preserve the existing daily automation; this integration creates no competing updater/task. Future monitored source upgrades must retain the fork and exact compatibility pins. When the managed CLI tuple changes, qualify the separate Anthropic copy and update its private provider binding through the same reviewed candidate/activation contract; do not silently point both roles at one executable or reuse a stale binding.

Select multiple chats using Ctrl/Shift and open Selected chat actions or the selection context menu for archive, delete, provider and explicit model changes. A destructive batch asks once and reports completed/skipped/failed items; it never stops active chats. Provider changes retain context without forced compaction. The managed active record now pins a stopScript: invoke that helper with -ActivePath D:\Tools\Reframe\active.json for an identity-bound idle maintenance quit through the native --quit channel. It waits actual owned exits and has no kill fallback.

Projects contains separate ChatGPT and Claude workspace trees. Identity includes provider and the full canonical folder path; matching basenames or the same folder under different providers do not merge chat lists. Pinned and Recents stay unified. Each workspace has a plus control opening New session with its exact provider/folder. Global New session uses Documents/ChatGPT or Documents/Anthropic for the selected provider, without moving existing folders/history. New session exposes Effort, inheriting the persisted Reframe default or native CLI settings; explicit effort persists for resume through --effort without changing global CLI settings.
